### 已交付切片：WASI REPL 会话合同、真实执行与 R0 恢复（`shenko-repl`）

新 crate `crates/shenko-repl` 实现 §19/§19.1 的 REPLProvider 合同与 WASI
preview1 后端（base `5959e455`，衔接 #103 的 WASI command IO）：

- `contract.rs`：`ReplProvider`/`ReplSession`（create/execute/inspect/
  checkpoint/restore/fork/cancel/reset/install_dependencies/dispose）、
  `ReplRuntime`（CPythonWasi/Pyodide/NodeWasm/BunWasm/JsWasm/Other 真实
  runtime 区分）、`CellKind`（Pure/DeclaredEffect/Unknown 重放边界）、
  `RecoveryLevel`（R0/R1/R2）。会话绑定 task/worker/scope、runtime/ABI、
  environment_generation、依赖锁、资源限制（当前如实 `enforced:false`）。
- `kernel.rs`：`KernelProfile` 把解释器绑定到 `ModuleSource::ModulePath`，
  create 时记 blake3，每个 cell 重读重验，模块被替换即拒绝执行
  （`REPL_KERNEL_UNAVAILABLE`），不悄悄换 runtime。`named_targets()` 如实
  报告：python-wasi、quickjs-wasm 可绑定；node-wasm、bun-wasm、pyodide 为
  具名不可用，不被 QuickJS/宿主 Node 冒充（R079–R081 边界）。
- `session.rs`：`WasiReplProvider`/`WasiReplSession` 在 `shenko-wasm` 上
  真实执行：每个 cell 一个真实 preview1 guest 进程，argv/env 精确传递，
  stdin 绑定已持久化的 cell 源码文件，stdout/stderr 落到独立文件并只回
  有限预览（blake3+截断标记）。guest 通过 `/home` 内声明的 state file
  跨 cell 进程保持解释器状态（`KernelProfile::persistence`）。
- `journal.rs`：宿主侧 JSONL journal（fsync）+ 每 cell 源码/输出文件；
  journal 不在任何 guest preopen 内。崩溃截尾如实标记并按 offset 修复，
  中途坏行硬失败。`restore`/`recover` 只对源码 hash 核验过的 Pure cell
  真实重放（replay 审计行入 journal）；DeclaredEffect 只留回执不重放
  （A15）；Unknown 报待对账；损坏记录如实 Corrupt。
- 诚实失败语义：`cancel` 报告 NotInterruptible（preview1 无中断机制）；
  `install_dependencies` 报告 Unsupported，environment_generation 不伪造
  移动（R083 未实现安装器）；COW mount 由 `shenko-wasm` 拒绝；
  `ResourceLimits` 声明但不声称强制；recovery_level 固定 R0。

新测试 4 个独立场景（`crates/shenko-repl/tests/wasi_repl.rs`，真实
wasmtime 执行合成 preview1 guest，非 mock）：① cell 执行+显式流+
guest state file 跨进程持久+ journal 持久+重启 reopen+checkpoint/reset/
fork；② 非零退出与 trap 均落 journal 且 trap 前输出持久+模块替换拒绝；
③ A15 恢复边界：只重放 Pure cell、effect 留回执、guest 状态计数证明；
④ 具名 kernel target 真实可用性区分。

仍缺（如实记录）：真实 CPython-WASI/Pyodide/Node/Bun 工件均未绑定
（无可用上游 WASM target 时具名条目保持 unavailable）；R1/R2 恢复
（对象/VM 状态）未实现，仅有 kernel 声明的 state-file 机制；包安装器
（R083 实装）、cell 超时/资源强制、interrupt、并发 cell 均未实现；
未接入 cordis Plugin 生命周期与 Store 任务记账（worker 绑定仍是
自由字段）。
