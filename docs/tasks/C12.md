## 当前已具备与真实差距
本次候选实现了本地有限 WASI backend 切片（尚未执行构建/原生验收）：

- Artifact 内容及完整版本记录先持久化，再切换 head；重开修复版本到 durable Inbox 的导入。原 flat content/meta 做一次显式迁移，保留原始文件，不补造已经丢失的历史。
- 模块按 CAS digest + typed invocation contract 绑定；HTTP action 原子接纳同一 Store 的 native TaskRecord 与 artifact.action 输入，现有 Cordis handler/dispatcher 负责 T1 Operation/Attempt → WASI guest → E1 → T2 TaskResult。没有 actions/*.json 第二动作账本。
- 202 是真实持久接纳，执行结果通过原 task/operation/attempt/evidence/result 查询；同 key 同 payload 返回原回执，冲突拒绝，新动作携旧 module digest 明确 stale。无 runtime 在 effect 之前 unavailable；armed unknown 只对账原 attempt，不盲重发。
- 二进制业务状态按文件 CAS + 前后 manifest 记录并解释；成功/失败结果走既有 native-child durable input，unknown E1 和 PUT/rollback 走 C11 同一 pending Inbox drain（source=playground）。代码/内容回滚恢复精确旧版本，保留新用户数据。

有限原生 HTTP / 重开配方见 [Playground WASI smoke](../development/playground-backend-smoke.md)。永久 consumer tests 明列九个独立行为（不是按函数数回避限制）；执行和实机证据由整合席补充。

仍开放：所有对话配置要求、完整 manifest/依赖/恢复闭包、actor 认证授权与 actor-scoped 去重、外部合作业务 DB 源事务、非 WASI runtime、动态 UI/compiler、常驻后端及后台调度。局部代码不等于 CFG01–03 或 PG01–05 全部验收通过。

这是接续任务，不要求重写已有代码。未合入候选由主控发布可取的 checkpoint 后复用；若候选尚不可取，先推进接口、独立实现或相邻可做项，不等待原作者在线。代码路径及实际候选会随后写入任务清单。
