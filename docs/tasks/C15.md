### 本切片进展（2026-10-29，source-only，未经构建/验收）
Linux 桌面 Computer Use 首个真实后端已落源：X11 经 x11rb 直连，`computer.use.session`/`computer.use.observe`/`computer.use.lease`/`computer.use.input` 四个 native kind 共享同一真实后端。lease/epoch/held 输入按共享显示域唯一作者化——DomainState 以 `x11/<归一化 transport>:<解析数字>/root<id>` 键共享，resource_id_base 不参与域身份；session owner 与 lease holder 绑定 admitted caller_instance_id（跨 native task 稳定的控制器身份），不是有限 task id。注入按原子发送单元复核：每个按键符/指针/按钮动作在 domain 锁下重验 lease token+epoch（Text 逐字符可中止），中途接管后剩余事件停发；释放只撤本动作新取的按住——已持有的 Shift/键/按钮不会被 helper 意外抬起；domain 身份按 x11rb resolver 实际 transport 归一（`unix:` socket 系拼写归 `unix:N`，任何 TCP 目标归 `tcp:host:N`），display>59535 因 resolver u16 `6000+N` 溢出被 typed-unavailable；domain watcher 无论 XI 是否可用都运行以消费广播 MappingNotify 使 keymap/shift 缓存失效，observe 的捕获与发布在 domain 锁内完成、close 无法在 capture 期间先返回；批内已送出事件计入 sent，action 内部分拒绝按 Partial 记账。观察在捕获前绑定 epoch、捕获后复验，default region 用实时 root geometry；指纹含实时 root+顶层窗口 geometry，失败即显式 unavailable。watcher 每域至多一条活线程：创建/存活检查/发布同临界区，watcher 在自己连接上协商 XI（≥2.1 才有 sourceid 分类；touch 掩码仅≥2.2），已退出线程被 join 并按需重建；后端 drop 停止并 join 全部 watcher。未实现：Wayland/VNC/RDP/Android/macOS/Windows provider 均为 typed unavailable；lease 只约束本产品不阻止人类直接输入；别名归一镜像 resolver transport（同一 socket 或同一 TCP endpoint 合并，localhost 等 TCP 拼写不与 unix socket 混并）；尚未构建运行，以受管构建内 Xvfb 实测为准。测试预算内删除的独立旧 token 拒绝场景（与 stale-observation 同一 revocation 路径）移交给 C15X11NativePrep 外部准备复核，不从套件假装覆盖。永久套件 4 个场景 9 个独立行为断言（观察/指针后验/真实按钮投递、同域冲突+takeover+epoch 围栏、布局陈旧围栏、armed-Unknown 不重放+自拥有死屏围栏）；typed-unavailable、close 围栏、store-reopen、dispatch 接线等交由即时真实探针覆盖。
