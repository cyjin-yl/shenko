## Findings corrected

| Finding | Correction and observable behavior |
| --- | --- |
| Original static manifest had a null public-build receipt, causing the required web job to fail before rebuilding. | A full build requires and validates the real public-closure receipt before mutating generated output. The prototypes-only type-check preparation remains independent. Adopted family source assets are derived once from the pin for both preflight and manifest generation. |
| Entering a Files directory removed the focused row; an empty directory could leave all parent-navigation shortcuts unreachable. | The persistent grid owns navigation and receives focus before directory replacement. Empty/loading/error states keep a keyboard owner; row selection has a single Tab stop. |
| Ctrl/Cmd+F cancelled browser Find even when the responsive layout hid Files search. | The application consumes Find only after focusing its visible search input. |
| Widget resize listeners outlived cancellation, focus loss or unmount, and unrelated pointers could change or commit the size. | A captured primary pointer owns the operation. Release includes the final coordinates; cancellation and retirement remove listeners, restore iframe interaction and avoid persisting intermediate sizes. |
| The pending-decision CTA changed views without reliably revealing and focusing the decision, especially when the phone was on its conversation list. | Each request identifies the direct thread and exact message. The actual mounted viewport pauses following, reveals and focuses the option, records the reading place and retires the request and observers. |
| Receipts from an older document revision could disable choices or hide a newer pending decision. | Rendering matches document, revision and action; pending-decision detection matches the current revision. Immutable older receipts remain available without settling the new revision. |
| Tablet IM hid search, scope and archive controls while retaining their state, and archived threads could not be collapsed. | Tablet layout retains a usable conversation sidebar and its controls. Archive expansion follows its explicit state. |
| The PR description and current contract named an old pin, 12 families and stale bundle sizes. | Current provenance records the exact 0.3.0 source, all 16 adopted adapter families and the two separately compiled authored Prototypes. Historical evidence remains bound to its original source. |

Nine new regression cases cover the corrections: two build cases, two widget
resize cases, one real semantic-document renderer case, two Files browser
cases and two IM browser cases. Existing suites are reused; this review does
not add a parallel inventory of near-duplicate tests.

## Failed attempts and acceptance limits

The original head's
[CI run 45427992035](https://github.com/cyjin-yl/shenko/actions/runs/45427992035)
failed the web job because the committed manifest lacked the real closure
receipt. That original result remains available; a later successful build
does not rewrite it. Previous compiler failures attached to older source
revisions are likewise preserved and not relabelled as current passes.

The local browser environment denied the required Chromium process/socket
operations. Those attempts provide environment evidence, not a browser pass.
The real-browser route uses the existing non-root doesvm user and installed
Chromium. During export of the full compiler checkout the host rebooted;
uptime and the missing exporter process confirmed interruption before the
compiler suite had started. The canonical build output and exported App
survived. A second export was retired before testing because of slow source
volume I/O; the replacement uses a fresh exact Git checkout and normal frozen
install. These interrupted preparations are not compiler test failures or
passes. No test assertion or sandbox setting was weakened to obtain a result.

Browser fixtures exercise the actual production App and controller with
existing demo data or deterministic HTTP/WebSocket reads. They do not prove
live backend/model behavior, physical touch hardware, assistive technology,
complete portable-family acceptance or an end-to-end production deployment.
CI's independent fresh rebuild and all six required jobs remain separate
merge conditions.
