# Developer Certificate of Origin（轻量版）

DCO 用于证明贡献来源和提交权，**不等于** owner 获得闭源或商业再许可权。商业双许可需要另行同意 `CONTRIBUTOR_LICENSE.md`。

提交贡献即表示你确认：

1. 你有权提交该贡献，且它来自你本人、已获得许可的来源，或法律允许的其他来源。
2. 你保留原始版权与许可声明，没有把第三方代码、私有凭据或未经授权内容冒充为自己的贡献。
3. 若贡献包含 AI 协助生成内容，你已审阅并有权提交；AI 尾注不替代真实作者或权属判断。
4. 若贡献属于雇主或他人授权范围，你已取得必要许可。

默认采用 PR 中的明确声明或提交说明记录即可，不要求每个 commit 都 GPG 签名，也不强制重复整段协议。需要更强审计时可在 commit 添加 `Signed-off-by: 姓名 <邮箱>`。

本 DCO 不改变原作者署名、正常 merge 获取 credit 的方式，也不要求贡献者放弃自己作品的其他使用权。
