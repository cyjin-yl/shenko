# Shenko 贡献者再许可协议（PROPOSED）

本协议用于让社区版保持开源，同时允许 owner 本人保留闭源/商业双许可。它不是 DCO，也不要求转让全部作品。

## 授权

每位贡献者（“你”）在自愿确认的前提下，保留其贡献的著作权、原作者身份和 Git 提交归属，并授予 `cyjin-yl` 一项**全球、永久、不可撤销、非独占、免版税**的许可，允许其在 Shenko 及其衍生版本中：

- 使用、复制、修改、汇编、发布、分发及公开展示你的贡献；
- 以 **AGPL-3.0-or-later** 发布包含该贡献的版本；
- 以闭源、专有或商业双许可方式使用、修改和再许可包含该贡献的 Shenko 版本。

该许可仅适用于你实际有权授权的 Shenko 贡献（代码、文档、测试、配置等），不涵盖第三方作品、未获授权的雇主成果或与 Shenko 无关的个人作品。第三方依赖继续遵守其原始许可证。

除正常开源许可所必需的范围外，本协议不授予专利、商标或品牌使用权；`Shenko` 名称与标识不因此自动获得商标授权。

## 不接受转让的内容

- 不要求你放弃原作者身份或 GitHub commit 归属。
- 不授权伪造你未参与的工作、伪造批准或把你的身份转给别人。
- 不把 DCO 的“我有权提交”扩大解释为“同意 owner 闭源商业化”。

## 确认方式

在你阅读本协议后，可在对应 PR 或 issue #54 中明确写：

> 我同意 docs/governance/CONTRIBUTOR_LICENSE.md 的条款，并仅就我有权贡献给 Shenko 的部分授予上述非独占再许可。

该确认与具体 PR/贡献范围绑定并保留记录。后续贡献在看到本协议后提交即按同一范围处理；未明确确认的既有贡献不自动追溯为商业授权。DCO 的来源声明见 `DCO.md`，两者独立。
