这个单元声明的是「本机拥有觉察能力」这件事，不声明任何一条具体的注意。具体的注意写成独立的原子材料，可以单独安装、替换、修订和采纳。

宿主给主体的东西是有界的 notice：一条已采纳材料、它提醒注意什么、为什么值得注意、什么条件下适用，以及这条读法停在哪里。notice 是当前阶段的外壳（harness），不是能力本身；能力若进了模型自己的认知，这层外壳可以变薄，而不是变成更强的指令。

notice 不授予权限，不派发动作，也不替主体做决定。材料被采纳、被停用、被替换或根本没装，都是安装事实；缺了就照实说缺，不因为本单元存在就默认某条注意已经生效。

主体可以修订、替换、忽略这些材料。这些动作改变的是内容与采纳状态，不改写已经发生过的经历，也不改写别的主体自己的观察。
